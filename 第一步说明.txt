A股选股工具 · 第一步：数据体检
========================================

【这一步做什么】

不选股、不交易、不下载大量数据。
它只回答一个问题：你这台电脑上，我们需要的数据到底拿不拿得到。

为什么先做这个：模型再漂亮，数据层塌了就全是空的。
尤其要验证一件事——财报数据里有没有"公告日期"。
没有它，回测就会提前知道还没公布的财报，跑出来的收益是假的。


【怎么用】

1. 双击 01_data_check.bat

2. 会弹出一个黑色窗口。第一次运行需要下载两个数据包
   （akshare 和 baostock，大约 50-100 MB），
   可能要等 2-10 分钟。别关窗口，让它自己跑。

3. 跑完后会自动打开一份《数据体检报告》网页，
   同时在 output 文件夹里生成两个文件：

     数据体检报告.html   ← 给你看的
     数据体检结果.json   ← 给 Claude 看的

4. 把 output 文件夹里的「数据体检结果.json」发回给 Claude，
   就能进行下一步。


【如果出错了】

· 提示 Python not found
  → 去 https://www.python.org/downloads/ 装一个 Python 3.11 或 3.12
    安装时一定要勾上 "Add python.exe to PATH" 这个选项
    装完再双击一次

· 下载包的时候卡住或报错
  → 多半是网络问题。关掉窗口，重新双击一次通常就好了

· 黑窗口一闪而过
  → 说明 bat 没跑起来。把这个文件夹的截图发给 Claude

· 其他任何报错
  → 直接把黑窗口里的内容截图，或者把 output 里的 json 发回来
    脚本写了兜底，单项失败不会中断，会继续测完其他项


【这一步会告诉我们什么】

· Python 环境和依赖能不能装上
· 全市场股票快照、历史行情（后复权）能不能拿
· 财报能不能按报告期一次拉全市场，带不带公告日期  ← 最关键
· 分红数据、行业分类、指数行情、退市名单、国债收益率
· 你的 2500 元，按不同持仓数，实际能买得起多少只股票
· 逐股拉取和横截面拉取的速度差多少（决定建库策略）


【关于资金】

脚本里默认按 2500 元测算。
如果想换个数字看看，用记事本打开 code\data_check.py，
找到最上面这一行改掉就行：

    我的资金 = 2500

改完保存，再双击 bat 重跑。


【安全说明】

这个脚本只读取公开市场数据，不会碰你的券商账户，
不需要任何账号密码，也不会向外发送任何东西。
所有文件都留在这个文件夹里。
